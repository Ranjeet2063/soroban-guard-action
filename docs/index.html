Enforced Soroban Security Invariants

CRITICAL SOROBAN-AUTH-01

State Mutation Authorization

Detects state-mutating functions accepting an Address without calling address.require_auth().

CRITICAL SOROBAN-SAC-01

Cross-Contract Token Transfer

Prevents invocation of token::Client.transfer(...) without verified sender authorization.

HIGH SOROBAN-STORAGE-02

Temporary Storage Misuse

Catches critical state (balances, owner keys) stored in ephemeral temporary storage that auto-purges on expiration.

HIGH SOROBAN-TTL-01

Storage TTL Bumping

Ensures contracts using ledger storage call extend_ttl() to avoid state archival.

HIGH SOROBAN-MATH-01

Unchecked Math Boundaries

Flags raw compound arithmetic on amounts and balances that could trigger unexpected VM aborts.

MEDIUM SOROBAN-PANIC-01

Naked .unwrap() Panic

Enforces custom typed #[contracterror] enums instead of raw panics.
